Part A: Programming (10 × 4 = 40 marks)

Q1. A helper for every request[4 marks]

Write async function requestJSON(url, options). Every later question uses it instead of calling libraryFetch directly.

  1. It calls libraryFetch(url, options) and, for a successful response (2xx), returns the body as an object. [1]
  2. For a 204 response, it returns null without reading the body (a 204 has no body, and res.json() would fail). [1]
  3. For any other status, it throws an Error whose message is the server's error text, and sets the error's status property to the status code. [2]
CallResult

await requestJSON("/api/books/99")throws an Error with message No book with id 99 and status 404
await requestJSON("/api/reservations/101", { method: "DELETE" }) (an existing reservation)returns null
